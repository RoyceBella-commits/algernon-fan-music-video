# 《纸做的阿尔吉侬》：ヨルシカ《アルジャーノン》MV 分镜与制作计划

## 说明
以 ヨルシカ《アルジャーノン》（4:14）和丹尼尔·凯斯《献给阿尔吉侬的花束》为素材的非官方 MV。风格以“纸偶剧场”（剪纸立体书）为主，穿插“进步报告”笔记本页。
本文是制作时使用的分镜与计划。为避免收录歌词，歌词一律以行号 L1–L33 表示（行号对应 `story/src/data/lyrics.public.json` 中的顺序）；笔记本上的中文都是对原著进步报告的意译，不是已出版译本的原文。

## 核心设定
- **僕＝纸老鼠阿尔吉侬，貴方＝查理**。整首歌是一只纸做的老鼠对做出它的人说的话。
- **查理本人只露出一双手**：面包师的手，指缝里有面粉。深夜，他在台灯下用撕下来的进步报告纸剪纸、搭剧场。舞台上的纸人查理和纸老鼠，演的是他自己的故事。
- **手工的精细度就是智力曲线**，和笔迹同步：
  - 开头：剪得歪歪扭扭，蜡笔点的眼睛一大一小，纸上是错别字。
  - 巅峰：激光雕刻级的镂空纸树、精密的立体书机关，纸上写满公式和外语。
  - 退化：纸是撕出来的而不是剪的，字又变回错别字。
- **材料**：横线笔记本纸（带查理的笔迹）、面包店牛皮纸袋、实验室方格纸、旧报纸。
- **色彩脚本**：
  - 台灯暖黄 + 牛皮纸棕（主歌 1）
  - 面包店晨橙（副歌 1）
  - 加入纸海的蓝（主歌 2）
  - 星图蓝金（副歌 2）
  - 冷白高反差（桥段）
  - 潮湿灰、褪色（副歌 3）
  - 柔和晨光（终副歌）
  - 单束追光后白场（尾奏）
- **运动语言**：
  - 纸偶按 12fps（一拍二）定格节奏动，带轻微抖动；摄影机 24fps 平滑运动，带轻微手持感。
  - 立体书机关做成“沿折痕立起”的 3D 动画。
  - 转场用翻页、纸层划过镜头、灯光变化。

## 歌词排版（V 家 PV 风格，日文）
- 基础层：明朝体（候选 Shippori Mincho B1 / Zen Old Mincho），逐字浮现，在下一句前 0.3s 淡出。按每个镜头的留白摆位，竖排、横排混用，带极淡的纸片投影。全片大部分时间都是这一层，干净、不抢画面。
- 只有约 6 处让字融进画面：
  - 0:07 L2：字和正在画的眼睛同时出现。
  - 0:55 L9：字沿迷宫通道排列。
  - 1:05 L10：落在名牌附近。
  - 2:28–2:37 L22–L24（同一句唱三遍）：三次分别是工整 → 错位 → 字距散开。
  - 2:37 L25：字从行上掉下来。
  - 3:27.8 L33：单独居中，用手写体（Klee One）。
- 片尾小字：アルジャーノン / ヨルシカ（fan-made）。

## 技术管线
> 以下是开工前的计划，保留原样作为记录。实际实现和目录以 README 为准，主要差异：抠图改用绿幕色键（`art/key.py`），没有用 rembg；放大改用 PyTorch 版 Real-ESRGAN（`art/upscale.py`），因为 ncnn 版在 Apple Silicon 上会输出错位的图块；没有用 Make Me a Hanzi；歌词改为按人声音节逐字同步（`analysis/lyric_timing.py`）。

- **项目目录**（见 README）：
  - `story/`（Remotion）
  - `art/`（提示词、原画、生图与抠图脚本）
  - `analysis/`（拍点、歌词时间）
  - `docs/`（封面、本文）
- **合成**：Remotion（npm 安装，会自带 headless Chrome），用 CSS 3D 搭纸层舞台。可复用组件：
  - `PaperLayer`：深度、投影、景深模糊
  - `PopUp`：沿折痕立起
  - `StopMotion`：12fps 取整加随机抖动
  - `Camera`
  - `LightRig`：台灯、追光、光斑
  - `NotebookPage`、`Handwriting`：逐字或逐笔画书写、错字划改、字形掉落
  - `Maze`：程序生成 + 立墙
  - `PaperTree`：分形生长 + 纸纹理
  - `Lyrics`
  - `PaperGrain`
- **生图**：
  - 命令：`codex exec --skip-git-repo-check -s workspace-write -C <dir> -i <参考图> "<prompt>"`，输出在 `~/.codex/generated_images/<id>/`，约 1672×941。
  - 先出设定稿（纸老鼠的三种精细度、纸人查理、手、台灯桌面环境），之后所有生图都用 `-i` 附上设定稿保持一致。
  - 元素在纯色底上生成，再用 rembg 抠图；如果 codex 能直接出透明底就跳过这一步。
  - 每张图生成后读图检查，不合格就重生成。
- **文字**：笔记本上的中文、阿尔吉侬名牌都用程序渲染，不让 AI 画字。
  - 稚拙阶段：手写字体，加逐字随机旋转、大小、基线抖动，再叠一层铅笔石墨纹理。
  - 巅峰阶段：霞鹜文楷 + 公式 + 制图线。
  - 可选：用 Make Me a Hanzi 的笔画数据做逐笔书写动画。
- **手部**：几张抠好的“手 + 剪刀 / 铅笔 / 蜡笔”静态图层，按路径移动；被剪、被画的效果全部由程序生成，避免 AI 生成连续手部动作。
- **放大**：realesrgan-ncnn-vulkan（macOS，GitHub release）对背景做 2× 放大，给推镜留余量。
- **音频**：FLAC 转 48k WAV 给 Remotion；uv 临时环境里用 librosa 算拍点和能量；成片用 ffmpeg 混入 AAC 320k。
- **输出**：1920×1080、24fps、H.264（CRF≈16），存为 `out/algernon_mv.mp4`。
- **需要下载**：Remotion 及其 Chrome（约 300MB）；字体（Shippori Mincho、Klee One、霞鹜文楷、一款中文手写体）；uv 环境（librosa、rembg 及模型约 200MB）；realesrgan-ncnn-vulkan（约 40MB）；可选 Make Me a Hanzi 数据（约 30MB）。
